# 候选股自动报告：第一版设计

日期：2026-10-08
项目：stock-candidate-report
状态：书面设计已于 2026-10-08 获用户批准

## 目标与验收

用户维护候选股代码与分组，运行一条命令获取数据、计算指标并生成与现有《候选股.xlsx》主要结构一致的新 Excel。第一版面向个人美股研究，优先免费数据源，手动运行。成功标准是运行可重复、结果可追溯、缺失数据明确、现有输入不被覆盖；并不承诺免费接口能填满全部预测年份。

## 项目与路径

独立 Python 3.12+ 项目，用 uv 管理依赖，源码计划放在 CODE_ROOT/stock-candidate-report。读取用户指定 workspace.toml 或显式环境参数以解析 code_root、data_root、config_root。缓存、原始响应、运行清单及导出表放在 DATA_ROOT/stock-candidate-report；股票清单和凭证配置放在 CONFIG_ROOT/projects/stock-candidate-report。源码只包含合成样例和测试，不包含个人持仓、候选清单或 API key。

项目尚未创建，本设计暂存于数据目录，实施时归档到仓库 docs/superpowers/specs/2026-10-08-stock-candidate-report-design.md 并提交。现有量化项目不改动。

## 使用流程

1. import-watchlist：只从原 Excel 读取 Symbol、名称与分组。合并单元格或空白分组只在有效股票行内向下继承；空行跳过，重复代码报出行号；非股票尾注不当作代码。原表的数值不作为新抓取数据或校验真值。
2. generate：按清单与指定报告年份获取数据、缓存并导出报告。默认报告年为运行日所在年份，支持显式 --year 2026；展示上一年实际及当年、未来两年的实际或预测，明确区分。
3. --refresh：强制更新；--offline：只使用缓存，过期值明确标注。单一股票失败不阻止其他股票生成。

不实现网页、自动交易、策略排名或定时任务。不注册账号、不购买数据；已有凭证按配置加载，没有凭证时相应接口跳过。

## 数据流与组件

清单读取 → 数据供应商适配器 → 标准化记录与 SQLite 缓存 → 指标计算 → Excel 导出及运行清单。

适配器负责网络调用与字段解析；标准化层保留代码、币种、指标、期间类型、财年标签、期间结束日期、实际或预期、会计口径、来源、抓取时间和供应商提供的预期日期；计算层不依赖网络；导出层不负责数据抓取。

先接 yfinance 行情、财报及可用预期；Alpha Vantage EARNINGS_ESTIMATES 作为可选年度与季度预期补充。FMP 留适配器扩展边界，不作为首版付费依赖。无实际测试前不宣称 Alpha Vantage 可免费覆盖 2028 或四个完整未来季度。

来源优先级按数据类型固定，禁止随意逐季度拼接不同口径；不同来源或 GAAP/调整后 EPS 不兼容时不计算增长或 NTM，并说明原因。来源未披露口径时标为未披露，不伪装成已校验一致。

## 时间、单位与指标

价格采用最新可用常规交易时段价格并记录时间、币种；不混用盘后价格。上一年收盘价采用当地交易日历中该年最后交易日收盘价。年初至今价格涨幅使用拆股一致、不含股息的价格序列，展示的历史原始收盘价与计算所用拆股修正基准若不同，保留并说明基准，避免跨拆股错误。

EPS 和营收按供应商明确的财年及结束日期映射；0y/+1y 不是固定 2026/2027，不能只靠运行年份推断。显示 FY 标签、结束日期及实际/预期属性，避免误称自然年。无法可靠映射的值不填。营收以百万原币显示，并提供币种；EPS 按每股原币显示，ADR 单位无法确认时标缺失。

营收增长 = 本期/上期 - 1，只在期间、币种和口径一致且上期为正时计算。EPS 增长也要求上期为正；亏损转盈利单独标为扭亏，负基数不显示误导性百分比。

NTM 首版采用未来四个连续、尚未结束财季 EPS 一致预期合计，并在表内明确标为“四个未来财季”，这只是季度滚动近似，不是精确从当天起十二个月的按日加权值。不包含已经结束但尚未披露的季度。必须验证季度日期、连续性、币种和 EPS 口径；不足四季不以年 EPS 或增长外推补齐。PE = 同币种、同每股单位的价格/该合计；合计为零或负数时标为不适用。

## 缓存与失败处理

价格缓存默认有效期 1 小时，预期 7 天，历史财务 1 天；报告展示各字段实际时间，抓取时间不能当作预期发布日。配置可覆盖有效期。每次运行保存不可变运行清单及本次使用的数据标识，支持追溯。

记录成功响应和结构化错误。限流、缺少权限、无覆盖、代码不存在、网络错误分别标记；指数退避只用于可重试失败，遵守供应商配额并避免无上限重试。无授权或权限失败不反复请求。在线刷新失败可回退缓存，但必须显示过期和失败原因；全部价格获取失败则仍输出诊断文件，并返回非零退出码。API key 不进入 URL 日志、异常文本或报告。

## 输出

Excel 第一张“增长和估值”：保留分组、代码、名称、上年收盘价、当前价格、涨幅、NTM PE、年度 EPS 与 SALES、增长率的顺序；表头随报告年生成，财年口径在标题和附近注释中说明。增加必要的时间/状态字段。

第二张“数据明细”：每项输入的财年、结束日期、币种、单位、实际/预期、来源、更新时间、口径与缺失原因，支持核对。报告数值不带伪造占位，缺失不得转成零。输出文件带运行时间戳，不覆盖输入；写入采用临时文件加原子替换，失败不留下貌似完整的成品。

计算结果由 Python 负责，Excel 是可核对的运行快照，不承诺改动 Excel 输入后自动重算。同步导出机器可读 JSON 运行清单，不另建重复报告。

## 验证

单元测试覆盖财年映射、季度连续性、拆股后涨幅、零与负 EPS、单位冲突、限流与缓存回退、分组和重复代码读取。使用合成供应商响应进行稳定离线测试，不为测试调用真实收费接口。

端到端测试从合成清单到 Excel，独立核对主要数字、工作表、数据类型、缺失标记和来源。现场用原候选清单进行一次真实运行，汇报成功、缺失、失败和缓存使用数量；免费接口无覆盖不视为填表成功。至少人工核对不同财年结束月份的代表股票，并检查导出表可读性。

完成标准：测试和格式检查通过；README 提供安装、清单导入、生成、离线与刷新命令；一份真实运行报告及完整覆盖诊断交付；凭证与真实数据不在源码仓库。


## 实施时的数据口径澄清
独立审阅后，财年标签仅接受供应商明确标签或经核验的逐股票配置；只有结束日期的数据保留明细但不自动贴 FY 标签。预测币种按指标来源或核验配置，每股单位不从 EQUITY 推断，EPS 实际口径不自动声明 GAAP。短年度与实际/预期 EPS 口径不明的比较留空。上述保守规则落实原设计的无法可靠映射则不填要求。
